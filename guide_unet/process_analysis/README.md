# 过程分析工具方向说明

本目录用于放置“过程分析工具”相关的脚本与说明，不直接承载主分割模型训练，而是服务于当前“现象原因解释”主线。

## 当前定位

- 该工具用于读取中间节点状态、计算节点语义一致性、阶段增量和相关可视化。
- 当前优先服务的问题是：解释 Stage 1 中 baseline 后期加速、no-skip 后期减速的现象原因。
- 新增脚本必须能产出可视化或量化证据，不能只延续旧的诊断、结构排序或模型改进路线。

## 当前优先方向

1. Stage 1 节点语义一致性曲线、语义速度和语义加速度。
2. `down1/down2/down3/down4/up1/up2/up3/up4` 的全网络分割 CAM 轨迹。
3. raw feature response 与最终概率图、真实前景区域之间的相关性和对齐程度。
4. CAM 与最终概率图、真实前景区域之间的相关性和对齐程度。
5. CAM/raw feature response 的速度、加速度、响应熵和前景/背景响应对比。

## 当前明确不建议的方向

1. 继续做旧断层诊断。
2. 继续做模型修复或模块改进。
3. 继续扩展结构依赖排序作为主线。
4. 改成分类任务 CAM。
5. 只用主观语言解释加速/减速现象，而没有对应图表和量化指标。

## 这一目录后续应放什么

- 现象原因解释相关的脚本原型。
- 节点语义一致性、CAM 相关性、速度/加速度、熵和 GT 对齐指标说明。
- 与 `scripts/current_phenomenon_cause/` 对应的示例可视化输出说明。
- 对旧方向脚本的归档说明。

## 一句话结论

当前最合理的过程分析工具路线是：

**围绕 Stage 1 加速/减速现象，使用节点语义一致性、全网络分割 CAM、raw feature response、相关性、速度/加速度、熵和 GT 对齐形成可视化与量化闭环。**
