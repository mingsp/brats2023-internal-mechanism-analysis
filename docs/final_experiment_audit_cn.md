# PPTT 正式实验审计

## 1. 当前判定

PPTT 的数学定义、模型适配器、受控观察器、已知过程验证、患者级转移统计、锁定式结构干预、第二架构迁移接口、图件和复现审计均已实现。三种模型、三个模型种子的 9 个分割权重和正式观察器均已完成；最终 V1 矩阵通过。V3 多种子患者级统计已按锁定配置启动，V4、V5 和最终论文图表必须等待 V3 的正式结果，因此当前不得写成“全部实验完成”。

## 2. V0-V5 判定

| 审计问题 | 当前结论 | 依据与边界 |
|---|---|---|
| 1. V0 是否通过 | 通过 | 像素守恒、混淆矩阵重构、净流平衡、指标变化重构和路径望远镜恒等式误差均为 0；短流程重放 SHA-256 一致。 |
| 2. 哪些作业通过 V1 | 9 个正式作业全部通过 | 有跳接 U-Net、无跳接 U-Net 和 TransUNet 的 seed 42/123/3407 均无失败节点。seed 42 的三种架构在 down1、down4、up4 共 9 个节点上通过冻结观察器参数随机化主控制；所有患者级均值和 95% 置信区间下界均大于 0。 |
| 3. 参数随机化双控制如何解释 | 主控制通过，重训诊断保留差异 | 冻结观察器主控制只改变网络模块，直接检验原读出关系是否依赖已训练表征。原“随机化后重训观察器”诊断中，有跳接 U-Net down4 和 TransUNet down1 未通过，说明随机特征仍可能被新观察器部分解码；该结果不再作为主忠实性门控，也没有被覆盖。 |

| 10. 是否可复现 | 当前代码和 V0-V2/V1 可复现 | 服务器 `153 passed, 2 skipped`；两个跳过项是 Linux 下不适用的 Windows junction 检查。环境、配置、权重、观察器、主随机化结果和诊断结果均保留。 |

## 3. V1 参数随机化审计

冻结观察器主控制使用 250 名 test 患者、10,000 次患者级配对自助法、固定随机化种子和原冻结模型最终概率。正式结果如下：

| 模型 | 节点 | 随机化减原始 JSD 均值 | 95% 置信区间 | 判定 |
|---|---|---:|---:|---|
| 有跳接 U-Net | down1 | 0.296105 | [0.290255, 0.301600] | 通过 |
| 有跳接 U-Net | down4 | 0.269913 | [0.264080, 0.275815] | 通过 |
| 有跳接 U-Net | up4 | 0.351051 | [0.349187, 0.352780] | 通过 |
| 无跳接 U-Net | down1 | 0.300728 | [0.295207, 0.306353] | 通过 |
| 无跳接 U-Net | down4 | 0.329094 | [0.323185, 0.334966] | 通过 |
| 无跳接 U-Net | up4 | 0.332003 | [0.329688, 0.334266] | 通过 |
| TransUNet | down1 | 0.258117 | [0.253151, 0.263096] | 通过 |
| TransUNet | down4 | 0.235213 | [0.231481, 0.238796] | 通过 |
| TransUNet | up4 | 0.411980 | [0.407849, 0.415975] | 通过 |

主控制和重训诊断的定义、原失败结果、文件契约及准入逻辑见 `docs/parameter_randomization_protocol_amendment_cn.md`。

## 4. V3 运行约束

1. 正式输出目录为 `results/v3_unet_pair`，不得混入 smoke、preflight 或 debug 结果。
2. 每个模型种子必须同时覆盖 125 名 val 患者和 250 名 test 患者。
3. 每个作业必须先读取并通过对应的 `v1_status.json`；缺失、失败或待定状态均由脚本硬阻断。
4. 患者轨迹保留离散节点状态、可靠性掩膜、真值、最终模型状态和切片标识。浮点 margin 只用于内存中形成可靠性掩膜，不参与 V3 统计且不重复落盘。
5. 紧凑轨迹 preflight 的首次结果与 `--resume` 重算结果在 10 张 Parquet 表上 SHA-256 全部一致，单病例文件约为 0.4-0.6 MB。
6. V4 候选转移、最低一致种子数、统计方向、患者单位和 10,000 次配对自助法均保持预注册值。

## 5. 禁止主张

1. 不得在 V3 完成前把任一 smoke 或旧 Stage 1 方向写成多种子患者级规律。
2. 不得将 U-Net 与 no-skip U-Net 的差异写成跳接的普适因果规律。
3. 不得把冻结观察器参数随机化解释成模型性能提升或跨架构机制等价；它只验证锁定读出关系依赖已训练表征。
4. 不得删除或改写重训观察器诊断中的未通过节点。
5. 不得在 `v4_trigger.json` 未触发时更换候选转移、降低条件或强制运行 V4。
6. 不得将 CAM、LayerCAM 或中间节点 Dice 纳入 PPTT 的像素状态转移定义。
7. 不得把 preflight、smoke、debug 或强制触发结果写成正式结论。

## 6. 唯一后续顺序

1. 完成 V3 六作业多种子患者级统计并核验完整性、重构误差、三种子方向和磁盘清单。
2. 仅在预注册触发条件成立时运行 V4；未触发时生成并保留 `NOT_TRIGGERED` 记录。
3. 使用真实 TransUNet 三种子资产运行 V5，评价接口迁移和过程输出完整性。
4. 生成中英文正式图件和结果清单，核验全部正式输出 SHA-256。
5. 根据最终结果更新本审计，再确定论文中的强主张、统计主张和边界。
