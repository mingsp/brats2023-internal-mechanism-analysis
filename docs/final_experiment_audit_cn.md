# PPTT 最终实验审计

## 1. 总体判定

PPTT 的数学定义、U 形网络适配器、受控观察器、已知过程验证、患者级转移统计、锁定式结构干预、第二架构迁移接口、图件和复现审计均已实现。服务器全测试通过，V0/V2 可从空目录逐字节重放。正式 BraTS2023 实证矩阵尚未完成，原因是 7 个预注册分割权重及其观察器需要长时间训练。当前状态为“方法实现完成，正式多种子实证待运行”，不能写成“全部实验完成”。

## 2. V0-V5 判定

| 审计问题 | 当前结论 | 依据与边界 |
|---|---|---|
| 1. V0 是否通过 | 通过 | 像素守恒、混淆矩阵重构、净流平衡、指标变化重构和路径望远镜恒等式误差均为 0；重放 SHA-256 一致。 |
| 2. 哪些节点通过 V1 | 正式判定待完成 | seed 42 的 U-Net 与 no-skip U-Net 八个节点在两病例 smoke 中均无失败节点，参数随机化控制通过；该结果只验证代码路径，不能替代三模型种子正式 V1。 |
| 3. V2 是否恢复已知机制 | 通过 | PPTT 的阶段、方向、区域、错误起源和分支归因准确率均为 1.0，指标重构误差为 0；相同构造中的 Grad-CAM 与 LayerCAM 区域 IoU 分别为 0.2824 和 0.2146。 |
| 4. V3 四个现象假设 | 正式结论均为不确定 | seed 42、两病例 smoke 观察到早期差距、中部状态变化和后期持续净流差异；终点交叉未复现，baseline-minus-noskip Dice 为 -0.0046，置信区间跨 0。缺少种子 123/3407，不能进行正式方向一致性判定。 |

| 6. V5 迁移状态 | 待资产 | TransUNet 三个种子均正确报告 PENDING_ASSETS。借用 U-Net 权重的两病例 debug 只证明接口能输出完整轨迹、转移张量、精确重构及 dF/dY/o，不能作为 TransUNet 迁移结果。 |
| 7. 三种子方向是否一致 | 尚不可判定 | 目前仅有两种 U-Net 架构的 seed 42 正式旧权重；其余 7 个模型矩阵权重缺失。 |
| 8. 哪些结果可进入论文 | 当前仅方法与构造验证可进入 | V0 数学性质、PPTT 定义、V2 已知过程恢复和独立比较可以作为方法验证。BraTS smoke、强制 V4 和借用 U-Net 的 V5 仅供开发审计；正式 V1/V3/V4/V5 完成后再筛选主文和补充材料。 |
| 9. 哪些主张必须禁止 | 见下节 | 禁止把未完成矩阵、smoke 或调试替代实验提升为科学结论。 |
| 10. 是否可复现 | 代码与短流程可复现，正式矩阵尚不完整 | 145 项测试通过、2 项平台检查跳过；服务器结果文件均登记并通过 SHA-256 校验。数据清单、seed 42 权重和短结果完整；缺失权重已显式记录，不进行伪补全。 |

## 3. 禁止主张

1. 不得宣称 PPTT 已在三个模型种子和第二架构上完成正式验证。
2. 不得将 seed 42、两病例 smoke 的方向写成群体规律或统计显著结论。
3. 不得将 U-Net/no-skip 的差异写成跳接的普适因果机制。
4. 不得将强制触发的 V4 调试结果写成结构路径选择性贡献；该调试结果没有同时通过选择性置信区间和 OOD 门槛。
5. 不得将借用 U-Net 资产的 V5 调试写成 TransUNet 迁移成功。
6. 不得用 CAM、LayerCAM 或既有节点 Dice 代替 PPTT 的像素状态转移定义。

## 4. 完成正式实证的唯一后续顺序

1. 运行锁定的 7 作业分割训练矩阵，不改变种子、模型配置或成功门槛。
2. 对全部 9 个模型作业训练并审查 V1 观察器，未通过节点保留断点，不进行结果导向替换。
3. 运行 V3 多种子患者级统计，并仅由 val 发现集决定 V4 是否触发。
4. 仅在触发成立时运行 V4；随后用独立 test 结果完成选择性、剂量、恢复和 OOD 判定。
5. 使用真实 TransUNet 权重和观察器运行 V5，仅评价方法接口迁移及新时序签名。
6. 重新生成中英文图件、结果清单和本审计文档，再决定论文主张。
