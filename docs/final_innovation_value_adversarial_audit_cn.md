# PPTT 创新性、解释价值与对抗式审查

## 1. 审查结论

PPTT 已形成可独立定义的方法贡献，不再依赖原有 Stage 1 曲线或 CAM 组合来成立。其核心创新不是线性观察器本身，也不是逐层计算 Dice，而是把医学图像分割网络的内部推理过程定义为像素决策状态沿有序节点的联合转移，并用真实类别条件转移张量保留端点指标丢失的像素配对关系。在此基础上，PPTT 能够区分修正、破坏、稳定错误与错误重编码，重构相邻节点的全部混淆矩阵和分割指标变化，并追踪最终决策的持续形成深度。

当前证据支持将 PPTT 定位为一种冻结模型、需要内部访问、面向稠密预测的事后过程性可解释分析方法。检索到的相邻工作分别覆盖逐层探针、预测轨迹、概念路径、分割表征恢复、输入归因和原型解释，但未发现与“真实类别条件像素转移张量 + 指标精确重构 + 持续性谱系”完全相同的方法组合。该结论是基于当前检索范围的创新性判断，不能表述为穷尽全部文献后的绝对首次证明。

从投稿风险看，现有方法与实验足以支撑一篇方法主导的二区至三区论文，并明显强于仅解释单个 U-Net 曲线的案例研究。V6 为一个锁定的过程候选补充了必要性、恢复性、区域特异性和剂量关系，使证据由纯观察诊断扩展到限定干预忠实性。V7 又在两种 U-Net 变体、三个种子和全部 250 名 test 患者上执行了完整 7×7 过程—恢复节点扫描，但预注册门控结论为 `INSUFFICIENT_NETWORK_COVERAGE`。因此，PPTT 的过程表示创新、数学性质和候选特异性干预价值已经成立，全网络干预一致性尚未成立。单一医学数据集、二维设置、观察器依赖和全路径干预覆盖不足，仍使顶级期刊或主会投稿处于高风险状态。

## 2. 当前最有力的过程结论与方法价值

### 2.1 终点指标压缩了更大的内部过程差异

三种子、250 名患者形成 750 个配对患者—种子样本。有跳接与无跳接 U-Net 的终点肿瘤 Dice 平均差异为 4.963 个百分点，95% 置信区间为 `[4.538, 5.397]`；中部正确像素破坏差异为 4.087 个百分点，95% 置信区间为 `[3.615, 4.593]`；解码后期持续净修正差异达到 18.855 个百分点，95% 置信区间为 `[17.855, 19.852]`，约为终点 Dice 差异的 3.80 倍。750 个配对样本中，有 86 个样本的终点 Dice 绝对差异不超过 2 个百分点，但其全路径过程距离中位数仍为 0.163。

这些数值给出 PPTT 最直接的方法价值：终点 Dice 只保留最终混淆矩阵，网络内部不同区间产生的修正、破坏和错误重编码会在终点相互抵消；PPTT 保留同一像素跨节点的联合身份，因此能把被终点压缩的过程差异重新分解出来。PPTT 不是重新绘制 Dice 曲线，而是在共同可靠像素支持上回答两个终点相近的模型是否通过相同的像素决策路径形成预测。

### 2.2 稳定结论不是后期加速，而是决策损失与持续恢复

原始单种子曲线中的后期加速与减速符号没有跨三个种子稳定复现。跨种子更稳定的结果是：有跳接与无跳接模型在中部正确像素破坏、错误重编码和解码后期持续净修正方面存在显著差异。持续性谱系进一步区分了短暂翻转与最终保留下来的修正，避免把某一节点的瞬时高值误写成最终决策已经形成。

这项否证结果本身构成方法价值。如果一种解释工具只能确认研究者预先相信的故事，它不具备可靠的诊断能力；PPTT 在同一协议下否定不稳定的加速叙事，同时保留跨种子稳定的过程模式，说明它能够约束而不是迎合主观解释。

### 2.3 观察过程能够生成并检验结构假设

V6 将验证集上锁定的 `up1->up2` 持续纠正候选映射到 `up2` 接收的 `down2` 结构变量，并在首次 test 干预前固定患者、种子、破坏方式、恢复剂量、匹配规则和统计阈值。746 个可评估患者—种子结果中，必要性效应量为 2.53–2.71，恢复性效应量为 1.99–2.31，区域特异性效应量为 1.06–1.21；三个种子均满足剂量单调关系，无跳接负控制为 0。该结果说明 PPTT 的过程输出不仅用于描述，还能把稳定的像素决策变化转化为可接受反事实检验的结构候选。

V7 把同一思想扩展到全部 7 个过程区间和 7 个恢复节点，共完成 1,500 个患者结果和 73,500 个预声明矩阵单元。所有数学、协议、模型复现和干预算子审计均通过，可评估区间的宏、微特异恢复效应均为正；但严格匹配后，每名患者可评估接收区间中位数仅为 1，没有达到至少两个种子覆盖 5/7 区间的门槛。因此 V7 证明了全网络扫描与失败审计能够正确运行，也定位了“持续纠正群与严格匹配对照交集过小”的适用性瓶颈，但不能升级为全路径因果证明。

### 2.4 可复用能力

PPTT 为医学图像分割网络分析提供四项可复用能力：在统一像素决策空间定位决策何时改变；将指标变化分解到具体的修正、破坏和重编码事件；区分瞬时变化与最终持续状态；把稳定过程候选转化为预注册的结构干预假设。它直接服务于模型比较、结构诊断、随机种子稳定性审查和失效定位，不以提高分割精度为目标，也不把当前证据外推为面向临床医生的病例决策解释。

## 3. 第一性原理：过程解释需要保留什么

### 3.1 分割网络的基本输出对象

医学图像分割的最终输出不是单个类别，而是每个像素的类别决策。若在有序内部节点处用受限观察器得到同一决策空间中的状态 `z_i(p)`，则内部推理过程的最小可观察单位是同一像素 `p` 从 `z_i(p)` 到 `z_j(p)` 的状态变化，而不是两个节点各自的平均 Dice。

对真实类别为 `y`、转移前状态为 `a`、转移后状态为 `b` 的像素计数定义三阶转移张量：

```text
T_ij[y,a,b] = number of pixels p satisfying y(p)=y, z_i(p)=a, z_j(p)=b.
```

沿 `b` 求和得到节点 `i` 的混淆矩阵，沿 `a` 求和得到节点 `j` 的混淆矩阵。因此，Dice、IoU、精确率、召回率和特异度的相邻节点变化均可由 `T_ij` 精确重构；多个节点转移的指标增量之和等于路径端点差。

### 3.2 为什么节点指标不能替代转移张量

V0 给出构造性反例。过程 A 与过程 B 的转移前后混淆矩阵完全一致，全部端点指标差为 0，但两个转移张量的 L1 距离为 6。过程 A 没有发生修正、破坏或错误重编码；过程 B 各发生 1 次。由此得到：

```text
相同端点混淆矩阵和相同端点指标，不推出相同内部决策过程。
```

数学上，端点混淆矩阵只包含 `T_ij` 的两个边缘分布，边缘化会丢失同一像素在两个节点之间的联合配对关系。只要某个真实类别下至少存在两个非零的转移前和转移后状态，满足相同边缘约束的联合转移通常不唯一。PPTT 所保留的正是这部分不可由节点指标恢复的信息。

### 3.3 方法的最小闭环

PPTT 的方法闭环由五个不可互换的计算部件组成：

1. 受控线性观察器：把异构中间特征映射到统一的最终决策空间，只回答最终决策何时可被线性读出。
2. 像素状态场：为每个节点、患者和像素记录离散决策及可靠性边界。
3. 条件转移张量：保存真实类别、转移前状态和转移后状态的联合计数。
4. 精确重构与事件分解：把指标变化分解为修正、破坏、稳定状态和错误重编码，并执行守恒检查。
5. 持续性谱系：区分瞬时翻转与最终保留下来的决策变化，定位最终正确或错误状态的形成深度。

CAM、LayerCAM、节点 Dice 和单张热图均不属于上述方法定义。它们只能作为独立比较，不能替代转移张量和持续性谱系。

## 6. 对抗式审查

### 6.1 质疑：这只是把混淆矩阵做成三维计数表

单个转移张量的计算确实简单，方法价值不应建立在计算复杂度上。构造性反例证明，三阶联合转移包含两个端点混淆矩阵及其指标无法恢复的配对信息；持续性谱系进一步保留跨多个节点的终点稳定关系。因此，方法贡献是定义了适合稠密预测过程解释的可守恒分析对象及验证协议，而不是声称发明复杂优化算法。

### 6.2 质疑：观察器可能只学会模仿最终输出

该质疑成立。PPTT 观察器的定义就是测量最终决策在中间特征中何时变得线性可读，不代表恢复网络唯一真实的隐含语义。单层 `1x1` 观察器、训练/测试隔离、患者置换、空间平移和冻结参数随机化降低了记忆与固定位置模式的风险，但不能把读出升级为直接因果机制。

### 6.3 质疑：探针可读不等于模型实际使用

该质疑由探针研究明确提出。[控制任务研究](https://aclanthology.org/D19-1275/)指出高探针精度可能来自探针容量，[Amnesic Probing](https://aclanthology.org/2021.tacl-1.10/)进一步表明可读信息不必然具有行为作用。PPTT 的观察性输出因此只能对通过控制的决策可读轨迹做过程诊断。V6 进一步检验 PPTT 预先定位的 `up1->up2` 持续纠正候选：破坏 `up2` 的 `down2` 输入会显著降低持续纠正，只恢复目标区域可部分恢复该过程，且效果大于等量匹配对照并随恢复剂量单调增加。该结果把这一个候选从“可读关联”提升为限定干预忠实性，但不把全部观察器轨迹升级为因果事实。

### 6.4 质疑：参数随机化是否足够

[Saliency sanity checks](https://proceedings.neurips.cc/paper_files/paper/2018/hash/294a8ed24b1ad22ec2e7efea049b8737-Abstract.html)说明解释应依赖已训练模型参数。PPTT 的冻结观察器随机化控制覆盖三种架构的三个代表节点并全部通过，能够排除完全参数无关的解释；但它目前只覆盖 seed 42 和代表节点，不能表述为对所有节点、全部种子的穷尽证明。

### 6.5 质疑：V2 的满分是否过于理想

是。V2 的已知过程被有意设计为线性可读，因此满分只证明实现能恢复满足假设的过程。节点 Dice 同样达到阶段定位准确率 1.0，故不能用 V2 声称 PPTT 在所有任务上优于节点指标。PPTT 在 V2 中的额外价值是同时恢复方向、区域、错误起源、分支和指标守恒。

### 6.6 质疑：第二架构是否足以证明通用性

不足。V5 证明同一数据集上的 TransUNet 可以接入受控观察器并生成完整转移与谱系输出，且通过患者和空间控制。它不证明零样本迁移、不同架构具有相同机制，也不覆盖三维网络或外部医学任务。

### 6.7 质疑：方法是否具有临床价值

当前价值主要面向模型开发、验证和审计，而不是直接向临床医生解释单次诊断。它可定位某类病灶像素在何处被修正、破坏或错误重编码，帮助研究者区分性能差异来自早期可读性、中部决策损失还是后期稳定恢复。若要主张临床可用性，还需要医生任务、三维病例和人因评估。

### 6.8 质疑：全局门控失败后再检验 `up1->up2` 是否属于结果导向选择

这一风险必须由顺序设计约束。原全局双指标门控继续记为失败，固定 `up3->up4` 的 V4 保持未触发；V6 不解释中部破坏，也不声称全局门控通过。`up1->up2` 只根据 val 划分的持续净恢复效应选择，候选身份、三种子、全部 test 患者、干预位置、空间平移、恢复剂量、匹配规则、效应阈值和 Holm 校正在首次干预前写入内容寻址锁。干预结论仅来自未参与候选选择的 test 患者。该设计支持候选特异性确认，但不支持把 V6 外推为完整路径搜索的确认性证据。

### 6.9 质疑：V7 为什么不能证明全网络因果机制

V7 的运行和算子审计通过，说明干净输出复现、空间破坏、完整根恢复、目标节点恢复和空值处理均符合锁定协议；它没有通过的是统计覆盖门控。严格持续纠正定义和等量分层匹配使多数患者—区间缺少足量目标或对照像素，因此正向宏微效应只来自实际可评估的稀疏区间。把这些效应外推到全部七个区间会混淆“在可评估位置有效”与“全路径普遍有效”。当前合理结论是候选特异性干预忠实性成立、全网络干预一致性未获支持。

## 7. 创新性判定

### 7.1 可守护的原创贡献

1. 为稠密分割定义真实类别条件的像素预测转移张量，把节点状态提升为同一像素跨节点的联合决策过程。
2. 建立转移张量与端点混淆矩阵、分割指标增量及路径望远镜恒等式的精确关系。
3. 用构造性反例证明端点指标对内部过程不可识别，从理论上说明联合转移对象的必要性。
4. 将瞬时转移扩展为持续正确、持续错误、修正、破坏和错误起源深度，使解释能够区分暂时翻转与终点形成。
5. 形成受控观察器、参数随机化、已知过程验证、多种子患者统计、独立划分候选选择、锁定干预追踪和跨架构适配的完整验证协议。

### 7.2 不应声称原创的部分

线性探针、`1x1` 卷积读出、知识蒸馏、逐层预测轨迹、混淆矩阵、患者级自助法、参数随机化和多种子验证均有成熟先例。PPTT 的贡献来自这些约束与新过程对象之间的逻辑闭环，而不是把常用部件逐项包装成新算法。

### 7.3 最终判定

在当前检索和正式实验范围内，PPTT 具备明确、可证明且能由结果体现的方法创新。最强价值是将“节点性能变化”转化为“哪些像素决策在何处被修正、破坏、重编码并最终保留”：后期持续净修正差异达到终点 Dice 差异的 3.80 倍，且 86 个终点差异不超过 2 个百分点的患者—种子样本仍具有 0.163 的中位全路径过程距离。该方法还能否证跨种子不稳定的曲线叙事，并把稳定过程候选转化为可检验的结构干预假设。该创新属于过程表示、精确重构和受控验证协议创新，强度高于现成 XAI 工具的简单组合；V6 证明其中一个候选可预测反事实干预行为，V7 则诚实限定了该关系尚不能覆盖全部网络区间。单数据集、二维设置和全路径干预覆盖不足仍限制其顶级期刊证据强度。

## 8. 主张审计

### high_risk_claims

1. “PPTT 证明了跳接导致后期加速”：V4 未触发，且加速度方向跨种子不一致。应删除。
2. “PPTT 恢复了网络真实语义”：观察器只证明最终决策的线性可读性。应改为“恢复受控决策读出轨迹”。
3. “PPTT 首次进行分割网络逐层过程分析”：2026 年分割 MLLM 工作已有逐层像素探针与恢复分析。应把首次性限定到联合转移、精确重构和持续性谱系。
4. “PPTT 已具备临床解释能力”：当前没有临床用户研究。应限定为模型开发与审计价值。
5. “PPTT 对任意网络通用”：目前仅验证两种 U 形架构和一个二维数据集。应改为“接口可迁移至所验证的 TransUNet”。
6. “PPTT 已在全网络证明过程—干预一致性”：V7 覆盖门控失败。应改为“完整扫描了所有预声明区间，并在可评估区间观察到正向反事实响应”。

### citation_mismatches

1. Tuned Lens 可支持逐层仿射观察器和预测轨迹先例，不能支持 PPTT 的像素转移张量原创性。
2. GIG 可支持全网络路径解释的相关背景，不能支持精确指标重构或像素错误谱系。
3. Agg2Exp 可支持医学三维分割解释的重要性，不能作为内部推理过程的直接先例。
4. 参数随机化文献可支持控制原则，不能把通过随机化测试解释为因果证明。

### downgraded_language

1. “证明网络机制”改为“在受控读出空间中定位稳定的像素决策转移模式”。
2. “通用方法”改为“具有架构适配接口，并在 U-Net 与 TransUNet 上完成验证的方法”。
3. 未经干预的观察结果使用“结构来源候选”；V6 结果只能写为“在锁定变量与干预算子范围内具有干预忠实贡献”，不能写成唯一真实因果机制。
4. “优于 CAM”改为“回答与输入归因不同的问题”；V2 只能报告已知过程下的构念差异。

### ready_for_submission

有条件为 `yes`。作为二区至三区方法论文，数学必要性、控制闭环、多种子患者统计、第二架构迁移和候选路径干预忠实性均已具备；正式写作必须遵守上述边界。若目标是 TMI、MedIA 或顶级主会，当前仍为高风险，原因是缺少外部数据和三维设置，且因果检验只覆盖一个结构变量与一组干预算子。

## 9. 实验冻结建议

V0-V7 正式协议已经完整执行。V4 未触发和 V7 覆盖不足都是有效的预注册结果，不应通过更换节点、降低阈值、放宽匹配或选择有利种子补做；V6 只回答锁定 `up1->up2` 候选的限定干预问题。现阶段继续追加同一 BraTS 二维设置下的相似指标不会显著提高创新强度，反而会削弱主线。论文核心应组织为：端点指标为何不能识别过程、PPTT 如何保留联合转移、控制实验如何约束观察器、真实数据如何发现稳定过程并否证不稳定叙事、候选过程如何预测反事实干预行为、全网络扫描如何审计适用范围、第二架构如何验证接口迁移。若继续增强因果覆盖，只能在独立验证数据上先锁定新的事件与对照构造，再使用未参与设计的数据检验，不能回到本次 test 结果上调参。
