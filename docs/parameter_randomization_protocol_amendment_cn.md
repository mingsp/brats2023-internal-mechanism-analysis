# V1 参数随机化控制协议修订

## 1. 修订目的

V1 用受控观察器把内部特征张量映射为像素类别概率。参数随机化控制需要检验：观察器输出是否依赖被读取节点中由已训练网络形成的表征，而不是依赖观察器自身的重新适配能力。

原控制在随机化节点模块后重新训练观察器。该设置同时改变网络表征和观察器映射，因而回答的是“随机特征是否仍可被新的线性观察器解码”。随机投影可能保留部分线性可分信息，所以这一问题不能作为观察器忠实性的唯一准入条件。

修订后的主控制固定原网络上训练完成的观察器，仅随机化被检验的网络模块。这样只改变内部表征，观察器映射、最终概率参照、患者集合和统计程序保持不变，能够隔离网络参数干预对既有读出关系的影响。

## 2. 原控制结果与保留原则

原“随机化后重训观察器”控制在 seed 42 的三个模型上完成，共使用 250 名测试患者，并检验首部、中部和末部节点。结果完整保留，不覆盖、不删除：

| 模型 | 未通过节点 | 随机化减原始 JSD 均值 | 95% 配对自助法置信区间 |
|---|---|---:|---:|
| 有跳接 U-Net | down4 | 0.000593 | [-0.000627, 0.001846] |
| 无跳接 U-Net | 无 | 所有检验节点均通过 | - |
| TransUNet | down1 | -0.001468 | [-0.002464, -0.000476] |

模块随机化前后 SHA-256 不同，全部拟合结果有限，患者数量、节点映射和目标概率均已核验。上述未通过不是运行时故障，而是原控制同时允许观察器重新适配所产生的可解释结果。它继续作为“随机特征可重新解码性”诊断，不再承担主忠实性门控。

## 3. 冻结观察器主控制

对模型种子 \(s\)、节点 \(v\) 和患者 \(n\)，记：

- \(Z_{n,v}\)：原模型在节点 \(v\) 的特征；
- \(Z^{\pi}_{n,v}\)：仅随机化节点对应模块后得到的特征；
- \(p_n\)：原冻结模型在相同采样像素上的最终类别概率；
- \(h_{v,r}\)：观察器种子 \(r\) 在原特征上训练并锁定的观察器；
- \(\bar h_v(\cdot)\)：多个锁定观察器概率输出的算术平均；
- \(D_{\mathrm{JS}}\)：Jensen-Shannon 散度。

原始读出误差为

\[
d^{\mathrm{real}}_{n,v}
=D_{\mathrm{JS}}\!\left(p_n,\bar h_v(Z_{n,v})\right).
\]

冻结观察器下的随机化读出误差为

\[
d^{\mathrm{frz}}_{n,v}
=D_{\mathrm{JS}}\!\left(p_n,\bar h_v(Z^{\pi}_{n,v})\right).
\]

患者级随机化效应定义为

\[
\Delta^{\mathrm{frz}}_{n,v}
=d^{\mathrm{frz}}_{n,v}-d^{\mathrm{real}}_{n,v}.
\]

若已训练表征与锁定观察器之间存在稳定的节点读出关系，随机化该节点模块后应使读出偏离原模型最终概率，因此预注册方向为

\[
\mathbb{E}_{n}\!\left[\Delta^{\mathrm{frz}}_{n,v}\right]>0.
\]

节点通过条件同时要求：

1. 所有锁定观察器输出均为有限值；
2. 患者级均值严格大于 0；
3. 10,000 次患者级配对自助法所得 95% 置信区间下界严格大于 0。

任一正式检验节点未满足条件，该模型种子的 V1 主控制即为未通过，不调整阈值、不更换节点、不改变随机化种子。

## 4. 重训观察器诊断

记 \(\widetilde h^{\pi}_{v,r}\) 为在随机化特征上重新训练的观察器，其效应为

\[
\Delta^{\mathrm{refit}}_{n,v}
=D_{\mathrm{JS}}\!\left(p_n,
\overline{\widetilde h}^{\pi}_v(Z^{\pi}_{n,v})\right)
-d^{\mathrm{real}}_{n,v}.
\]

该量检验随机化表征中是否仍存在可被新观察器恢复的线性可解码信息。它与冻结观察器主控制回答不同问题，因此只报告诊断状态，不参与 V1 的通过或未通过判定。

## 5. 锁定设置

本次修订仅改变观察器在参数随机化后是否允许重新拟合，其他设置全部锁定：

| 项目 | 锁定值 |
|---|---|
| 正式模型种子 | seed 42 |
| 模型 | 有跳接 U-Net、无跳接 U-Net、TransUNet |
| 检验节点 | 每个模型拓扑顺序中的首部、中部和末部节点；当前三种适配器对应 down1、down4、up4 |
| 评估集合 | 250 名 test 患者 |
| 观察器集合 | 原模型上已训练并通过有限性检查的 seed 17、29、43 观察器 |
| 最终概率参照 | 原冻结模型在相同缓存像素上的最终类别概率 |
| 参数随机化基准种子 | 20260716；每个模型和节点通过稳定派生种子确定 |
| 统计方法 | 患者级配对自助法，10,000 次 |
| 统计基准种子 | 20260715；按模型、节点和控制类型稳定派生 |
| 通过方向 | 随机化减原始 JSD 的均值和 95% 置信区间下界均大于 0 |

seed 123 和 seed 3407 未预注册参数随机化控制，其主控制状态记为 `NOT_APPLICABLE`，不因缺少随机化报告而阻断其余 V1 检验。该设置不把 seed 42 的控制结果外推为跨种子统计结论；它只作为固定的实现忠实性检查。

## 6. 输出与审计

冻结观察器主控制写入：

- 单作业明细：`parameter_randomization_frozen_sensitivity.parquet`；
- 单作业状态：`parameter_randomization_frozen_status.json`；
- 矩阵状态：`parameter_randomization_frozen_matrix_status.json`。

原重训观察器诊断继续保留：

- 单作业明细：`parameter_randomization_sensitivity.parquet`；
- 单作业状态：`parameter_randomization_status.json`；
- 矩阵状态：`parameter_randomization_matrix_status.json`。

V1 汇总同时登记 `parameter_randomization_status`、`parameter_randomization_control_mode`、正式种子集合和 `retrained_randomization_diagnostic_status`。主门控只读取冻结观察器报告，重训诊断不得覆盖主状态。

## 7. 执行顺序

1. 核验原模型权重、观察器权重和已有重训诊断的哈希与完整性；
2. 对三个 seed 42 模型运行冻结观察器主控制；
3. 审查每个节点的患者数、模块哈希、有限性、均值和置信区间；
4. 重新运行 V1 汇总；
5. 仅当 V1 正式矩阵通过时进入 V3 多种子患者级统计。

任何主控制未通过时，流程停在 V1 并保留原始输出，不通过修改方向、阈值、患者集合或节点选择补成通过结果。
