# V9 TransUNet 区域特异性前瞻确认规格

## 1. 研究问题

V8 在验证集发现并锁定了 `bottleneck_to_up1`，正式测试中必要性、目标恢复和剂量关系均跨三个种子成立，但该路径的 `10 x 10` 特征网格无法提供不少于 8 个同类别、同边界层和同激活层的匹配对照位置，因此区域特异性不可评估。V9 只回答一个问题：

> 在不修改 V8、不降低匹配门槛且不读取新路径测试干预结果的条件下，加入验证集匹配可行性准入后，PPTT 能否前瞻性选择一条可干预路径，并在未接受过 V8 干预的测试病例上同时通过必要性、恢复性、区域特异性和剂量关系？

## 2. 与 V8 的隔离

1. V8 的候选、阈值、结果和失败状态保持不变。
2. V9 候选空间仍为 V8 在读取验证结果前声明的四条 TransUNet 解码接收路径，不新增路径、通道或空间位置。
3. 候选选择只读取验证集轨迹、验证集源图像和模型激活，不读取 V9 测试干预结局。
4. 正式确认队列固定为 V8 三个种子中均在任何前向干预前以 `INELIGIBLE_TARGET_FEATURE_POSITIONS` 退出的共同患者。每个入选文件必须具有空 `conditions`、空 `effects` 和空 `audit`。
5. V9 输出写入独立目录，不覆盖或合并 V8 文件。

## 3. 验证集可行性准入

对每个模型种子、患者和候选路径，沿用 V8 的目标切片、目标像素、稳定正确对照池、空间映射、类别分层、边界分层和激活范数分层，计算：

- 目标像素数不少于 32；
- 目标特征位置不少于 8；
- 一一无放回匹配位置不少于 8。

候选必须先通过 V8 的跨种子过程效应门控，再要求三个种子各有不少于 20 名匹配可评估验证患者。合格候选按验证集跨种子标准化效应最小值降序选择，平局依次按均值和拓扑顺序选择；最多登记一条路径。无候选时记录 `NO_FEASIBLE_TRANSUNET_CANDIDATE` 并停止。

## 4. 协议锁

首次 V9 测试干预前锁定：候选路径、26 名共同未干预患者的有序清单、三组模型与观察器哈希、V8 原始状态哈希、验证可行性资产、代码提交与源树哈希、空间平移算子、恢复剂量、匹配规则和统计阈值。锁定后不得换候选、患者、区域、算子或门槛。

## 5. 唯一干预族

保持 V8 算子不变：`Clean`、空间循环平移 `Corrupt`、目标区域恢复、等量匹配对照区域恢复，以及 `0.25/0.50/0.75/1.00` 四级目标恢复剂量。主要结局仍为固定持续纠正像素上的真实类别保持率，观察器不作为干预结局。

## 6. 成功门控

至少两个模型种子同时满足：

- 必要性：`Clean - Corrupt > 0`；
- 恢复性：`Target Restore - Corrupt > 0`；
- 区域特异性：等量目标恢复高于匹配对照恢复；
- 剂量关系：总体恢复曲线单调，且患者级单调比例达到锁定门槛；
- 算子审计：路径张量身份、完整恢复误差、目标恢复误差、循环平移多重集合和钩子清理全部通过。

V9 使用 `alpha = 0.025`，用于控制 V8 与 V9 两轮前瞻性检验的总体错误率；端点与种子内部继续使用全局 Holm 校正。最低配对标准化效应保持 `0.8`，每个端点每个种子至少 20 名患者，均不低于 V8。

## 7. 允许结论与停止条件

全部门控通过时，只允许表述为：PPTT 在预声明 TransUNet 路径空间内，经验证集过程效应和干预可行性联合筛选，前瞻性预测了一条在未干预测试子队列上具有必要性、恢复性、区域特异性和剂量关系的结构变量。

任一门控失败时保留原始失败状态，不再更换候选或调整协议。无论结果如何，均不得把 V9 写成整个网络的唯一真实因果机制证明，也不得将 V8 的区域特异性补记为通过。
