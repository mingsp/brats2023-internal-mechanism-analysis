# PPTT 跨架构全网络像素决策过程因果抽象设计规格

## 1. 当前阶段的唯一问题

本阶段只检验一个明确、可证伪的问题：

> 在 BraTS2023 上，U-Net 与 TransUNet 是否能够由同一个高层像素决策状态转移模型近似描述，并且该模型能否预测两个网络全部预声明宏观节点受到状态交换干预后的下游反事实轨迹？

研究对象由三部分组成：

1. **跨架构主体**：baseline U-Net 与 TransUNet；
2. **结构对照**：no-skip U-Net，用于检验方法能否识别移除跨尺度连接后产生的全路径过程变化；
3. **数据范围**：BraTS2023，沿用已经冻结的训练、验证和测试患者清单。

本阶段不增加新的医学数据集，不增加额外主架构，不重新训练分割模型，也不把研究目标扩展为所有网络的普适规律。no-skip U-Net 不是额外架构主体，不能用来代替 U-Net 与 TransUNet 的跨架构检验。

### 1.1 方法主轴与验证层级

PPTT 只由三个连续计算部件构成：

1. **过程状态抽象**：把异构节点特征映射为统一的像素决策关系状态，并保留同一像素沿深度的身份；
2. **高层状态干预**：把指定的高层状态交换通过闭式最小范数算子翻译到当前节点特征；
3. **全路径干预对齐**：比较高层过程模型预测与真实网络在全部后续节点及最终输出上的反事实状态轨迹。

统一检验关系为：

\[
\alpha_m\!\left(
N_m^{\operatorname{do}(\omega_{m,r}(q))}(x)
\right)
\approx
H^{\operatorname{do}(S_r=q)}\!\left(\alpha_m(x)\right).
\]

其中，\(\alpha_m\) 是架构特异的状态读取映射，\(\omega_{m,r}\) 是高层干预到节点特征的翻译算子，\(H\) 是不接收架构标识的高层状态转移模型。验证只回答三个问题：架构内是否忠实、U-Net 与 TransUNet 之间是否双向迁移、方法是否能识别 baseline/no-skip 之间超过随机种子波动的全路径过程差异。

自然源配对、可靠性门控、分布外审计、零空间控制、观察器随机化和深度置乱均为上述统一检验的有效性约束，不构成并列方法模块。no-skip U-Net 只用于结构敏感性验证，不用于逐条分析跳接作用。

若全部正式门控通过，允许形成的最高结论为：

> 在 BraTS2023、预声明的 U-Net 与 TransUNet 模型及其三个随机种子上，同一个低容量像素决策状态转移模型能够近似预测全部八个宏观节点干预后的抽象反事实轨迹，因而在该实验范围内构成两个异构分割网络的近似高层因果抽象。no-skip 结构对照进一步表明，该分析能够识别结构改变引起的过程差异。

该结论不等于两个网络共享相同的卷积、注意力或信息传递路径，也不等于证明了网络唯一真实的内部机制。任一全网络门控失败时，必须按第 13 节降级结论，不换节点、不删失败条件、不降低阈值。

## 2. 机制层级的重新定义

### 2.1 不再回答局部结构是否重要

某条跳接、某个注意力模块或某片空间区域是否影响输出，属于架构特异的局部路径问题。它可以提供局部因果证据，但不能回答不同架构是否通过同一种高层决策过程形成分割结果。

本设计把机制层级提升为：

> 同一像素的决策状态如何沿网络深度发生保持、修正、破坏和错误重编码，以及不同低层网络在受到同义状态干预后，是否产生由同一个高层过程模型预测的后续状态变化。

因此，共同机制指**共享高层状态空间、共享转移规律和共享干预语义**，而不是共享低层物理边。

### 2.2 为什么这是过程性可解释分析

终点 Dice 只汇总最终预测，无法确定同一像素在中间节点经历了什么。PPTT 保留像素身份，并沿网络拓扑记录其状态序列：

\[
\Gamma(p)=\left(S_1(p),S_2(p),\ldots,S_8(p),S_Y(p)\right),
\]

其中，\(S_1,\ldots,S_8\) 对应八个宏观内部节点，\(S_Y\) 对应最终分割输出。状态变化直接对应修正、破坏、错误重编码和持续状态，因此解释对象是输出形成过程，而不是终点热图或单个性能分数。

### 2.3 可读信息与被使用信息必须区分

线性观察器能够把节点特征映射为像素决策状态，但可读不代表网络后续计算使用了该状态。因果抽象成立还必须满足：

1. 高层状态干预能够被确定地翻译为低层特征编辑；
2. 低层编辑确实在目标节点实现预期状态；
3. 后续节点和终点的反事实状态与高层模型预测一致；
4. 等范数零空间、随机观察器和深度置乱对照不能产生同等一致性。

## 3. 验证对象与全网络节点

### 3.1 架构角色

主验证集合定义为：

\[
\mathcal M_{\mathrm{main}}
=\{\text{U-Net},\text{TransUNet}\}.
\]

结构对照集合定义为：

\[
\mathcal M_{\mathrm{control}}
=\{\text{no-skip U-Net}\}.
\]

每个模型沿用三个冻结随机种子 \(\{42,123,3407\}\)。模型权重、患者清单和节点适配器必须先核验 SHA-256；若资产缺失或哈希不一致，状态记为 `BLOCKED_ASSET_MISMATCH`，不得静默重训或替换。

### 3.2 八个规范化宏观节点

两个主架构均映射到相同的拓扑角色序列：

\[
\mathcal R=(E_1,E_2,E_3,E_4,D_1,D_2,D_3,D_4).
\]

其中 \(E_r\) 表示由浅入深的四个编码阶段，\(D_r\) 表示由深到浅的四个解码阶段。U-Net 的实际节点对应现有 `down1--down4` 与 `up1--up4`；TransUNet 由冻结适配器按编码深度和解码分辨率映射到同一拓扑角色。

“全网络”在本研究中严格表示：

- 八个宏观节点全部进入观察、干预、控制与统计；
- 干预任一节点后同时捕获其全部下游节点和最终输出；
- 最坏节点决定全网络结论。

它不表示枚举每个卷积层、注意力头或通道。节点集合在读取正式结果前锁定，不得按结果重新划分。

## 4. 统一像素决策状态空间

### 4.1 节点状态读取

对模型 \(m\)、节点 \(r\) 的原生特征 \(h_{m,r}\)，采用已通过准入审计并冻结的单层线性观察器：

\[
L_{m,r}=\mathcal A_{m,r}(h_{m,r})
=\mathcal R_{m,r}(W_{m,r}h_{m,r}+b_{m,r}),
\]

其中 \(W_{m,r}\) 只沿通道维投影，\(\mathcal R_{m,r}\) 是固定的空间对齐算子。观察器以冻结分割模型的最终概率图为训练目标，不参与分割模型训练，也不向高层模型传入架构标签。

### 4.2 架构无关的五状态定义

给定真实类别 \(y(p)\) 和节点预测 \(\hat y_{m,r}(p)\)，每个像素映射为：

\[
\mathcal S
=\{\mathrm{BC},\mathrm{FC},\mathrm{FP},\mathrm{FN},\mathrm{FW}\},
\]

其中：

- \(\mathrm{BC}\)：真实背景且预测背景；
- \(\mathrm{FC}\)：真实前景且预测为正确前景类别；
- \(\mathrm{FP}\)：真实背景但预测为前景；
- \(\mathrm{FN}\)：真实前景但预测为背景；
- \(\mathrm{FW}\)：真实前景但预测为另一前景类别。

该定义只描述真实类别与当前决策的关系，不依赖通道数、卷积或注意力结构。正式统计只纳入通过多观察器一致性和边界可靠性门槛的像素，同时报告有效覆盖率，避免用高一致率掩盖低覆盖。

### 4.3 状态转移的解释含义

相邻节点状态变化被唯一映射为四类过程事件：

- 错误状态转为 \(\mathrm{FC}\) 或 \(\mathrm{BC}\)：修正；
- 正确状态转为任一错误状态：破坏；
- \(\mathrm{FP}\)、\(\mathrm{FN}\)、\(\mathrm{FW}\) 之间变化：错误重编码；
- 状态不变：持续。

这些事件均由同一状态轨迹确定，不再作为相互独立的解释模块堆叠。

## 5. 共享高层状态转移模型

### 5.1 模型形式

高层模型 \(H\) 是一个非齐次、低容量有限状态过程。内部节点之间以及最后一个节点到终点的转移分别为：

\[
S_{r+1}\sim K_r(\cdot\mid S_r),
\quad r=1,\ldots,7,
\]

\[
S_Y\sim K_8(\cdot\mid S_8).
\]

每个 \(K_r\) 是五状态条件转移矩阵。给定节点 \(r\) 的高层干预 \(\operatorname{do}(S_r=q)\)，模型对后续节点 \(t\) 的预测为：

\[
P_H(S_t\mid\operatorname{do}(S_r=q))
=\mathbf e_q^{\top}K_rK_{r+1}\cdots K_{t-1},
\]

对终点的预测为：

\[
P_H(S_Y\mid\operatorname{do}(S_r=q))
=\mathbf e_q^{\top}K_rK_{r+1}\cdots K_8.
\]

### 5.2 三个冻结模型

只在 BraTS2023 验证集上估计：

1. \(H_U\)：由 U-Net 轨迹估计；
2. \(H_T\)：由 TransUNet 轨迹估计；
3. \(H_{\mathrm{shared}}\)：先对患者、种子和架构等权，再合并估计；该模型不接收架构标识。

Dirichlet 平滑、患者权重、状态覆盖和核估计规则在正式测试前冻结。正式测试不重新估计任何 \(K_r\)。

### 5.3 跨架构检验逻辑

同一高层机制不能只靠 pooled 拟合成立，必须同时通过三项检验：

1. \(H_U\) 能预测 TransUNet 的干预轨迹；
2. \(H_T\) 能预测 U-Net 的干预轨迹；
3. \(H_{\mathrm{shared}}\) 在两个架构上相对各自特异模型没有超过正式运行前锁定的容差。

前两项是双向跨架构迁移，第三项排除共享模型只是平均后得到的表面折中。

### 5.4 一阶过程假设的准入检验

共享模型采用一阶状态转移并非默认成立。正式 test 前，在 validation 患者上执行五折交叉验证，将一阶模型与只用于诊断的二阶历史模型比较：

\[
\Delta\epsilon_{\mathrm{hist}}
=\epsilon(H^{(1)})-\epsilon(H^{(2)}).
\]

若任一规范化节点上二阶模型使 held-out TV 误差降低超过 0.03，且患者级 95% 置信区间下界大于零，则记为 `HIGH_LEVEL_MODEL_MISSPECIFIED`，停止正式 test 干预。二阶模型不得在读取 test 后作为补救模型切换。该准入只检验当前五状态是否足以承载过程记忆，不形成额外结果主线。

## 6. 输出约束的最小范数状态交换

### 6.1 从高层干预到低层特征编辑

对节点 \(r\) 的目标输出像素集合 \(\Omega\)，令 \(R_{\Omega,r}\) 表示原生节点网格到目标像素的固定线性空间映射，\(W_r\) 表示冻结观察器权重。自然源像素与基础像素之间的观察器对数几率差记为 \(\Delta L_\Omega\)。低层编辑定义为：

\[
\delta H_r^*
=\arg\min_{\delta H}\|\delta H\|_F^2
\quad\text{s.t.}\quad
R_{\Omega,r}\delta H W_r^{\top}=\Delta L_\Omega.
\]

其 Moore--Penrose 闭式解为：

\[
\delta H_r^*
=R_{\Omega,r}^{+}\Delta L_\Omega(W_r^{+})^{\top}.
\]

节点干预后的特征为：

\[
H'_r=H_r+\lambda\delta H_r^*,
\qquad
\lambda\in\{0,0.25,0.5,0.75,1\}.
\]

该算子只在实现指定高层状态所需的观察器行空间内寻找最小编辑，不学习架构特异的非线性对齐函数。

### 6.2 自然源—基础配对

正式配对遵循以下固定条件：

1. 源像素与基础像素具有相同真实类别；
2. 两者在节点 \(r\) 的可靠高层状态不同；
3. 优先同患者匹配，不足时在同一数据划分内按真实类别、边界距离、空间尺度和特征范数分层匹配；
4. 每名患者、每个状态和每个节点设置相同采样上限；
5. 没有合格来源时记为不可评估，不更换状态定义或跨划分取样。

### 6.3 算子有效性审计

每次编辑必须记录：

- 目标对数几率重构误差；
- 目标状态实现率；
- 编辑范数及其相对验证集自然差分的分位数；
- 非目标空间读出泄漏；
- 全部下游节点状态与最终输出；
- 完整恢复后的输出误差；
- 模型、患者、节点、状态、剂量、种子和代码哈希。

编辑范数或泄漏超过验证集锁定门槛时，该样本记为 `INTERVENTION_OOD`，不能作为无效应样本混入统计。

## 7. 全路径干预一致性

### 7.1 网络反事实轨迹

在节点 \(r\) 施加状态交换后，网络产生：

\[
\Gamma^{\operatorname{do}(q)}_{m,r}(p)
=\left(S'_{r}(p),S'_{r+1}(p),\ldots,S'_8(p),S'_Y(p)\right).
\]

正式分析比较高层模型与低层网络在每个后续深度的患者等权状态分布，而不是只比较终点：

\[
\epsilon_{m,s,r,q,t,c}
=\operatorname{TV}\!\left(
P_{N_{m,s}}(S_t\mid\operatorname{do}(S_r=q),y=c),
P_H(S_t\mid\operatorname{do}(S_r=q))
\right).
\]

其中 \(c\in\{\mathrm{BG},\mathrm{ED},\mathrm{NCR/NET},\mathrm{ET}\}\) 表示背景、水肿、坏死/非增强肿瘤核心和增强肿瘤。高层模型不接收类别标识；类别分层用于检验统一状态定义是否掩盖某一肿瘤亚区的失败。

节点—状态的全路径误差为：

\[
\epsilon^{\mathrm{path}}_{m,s,r,q}
=\max_{t,c}
\epsilon_{m,s,r,q,t,c}.
\]

全网络误差由全部节点、可评估源状态和下游深度中的最坏条件决定：

\[
\epsilon^{\mathrm{net}}_{m,s}
=\max_{r,q,t,c}\epsilon_{m,s,r,q,t,c}.
\]

### 7.2 为什么不能只支持某一条路径

八个节点必须逐一执行同一协议。某个节点通过不能替代其他节点；平均值不能掩盖失败节点；某条跳接或注意力路径的局部恢复也不能替代全路径状态干预。若任一节点因覆盖、观察器、算子或抽象误差失败，只能报告通过的局部范围，不能称为全网络机制。

## 8. 同一核心实验中的非空洞化控制

### 8.1 等范数观察器零空间控制

令 \(P_r=W_r^+W_r\) 为观察器行空间投影，对随机矩阵 \(U\) 构造：

\[
\delta H_r^{\perp}=cU(I-P_r),
\qquad
\|\delta H_r^{\perp}\|_F=\|\delta H_r^*\|_F.
\]

在数值容差内，该编辑不改变目标任务读出。定义任务编辑和零空间编辑相对同一高层反事实目标的增益：

\[
G_{\mathrm{task}}
=\operatorname{TV}(P_{\mathrm{clean}},P_H^{\operatorname{do}})
-\operatorname{TV}(P_{\mathrm{task}},P_H^{\operatorname{do}}),
\]

\[
G_{\mathrm{null}}
=\operatorname{TV}(P_{\mathrm{clean}},P_H^{\operatorname{do}})
-\operatorname{TV}(P_{\mathrm{null}},P_H^{\operatorname{do}}),
\]

\[
\Delta G=G_{\mathrm{task}}-G_{\mathrm{null}}.
\]

任务编辑应使网络靠近高层反事实目标，零空间编辑应保持接近 clean 状态。

### 8.2 顺序、标签和观察器控制

同一正式汇总同时包含：

- **深度置乱**：置乱 \(K_1,\ldots,K_8\) 的顺序，检验结果是否真正依赖网络过程顺序；
- **状态置换**：固定置换五状态标签，检验状态语义是否必要；
- **观察器随机化**：沿用冻结观察器参数随机化审计，排除任意投影均能通过；
- **架构特异模型**：用同容量的 \(H_U\) 和 \(H_T\) 作为共享模型的上界，而不是额外方法。

这些控制不形成平行实验线，只回答高层抽象是否可能由粗粒度、标签边缘分布或观察器自由度造成。

## 9. no-skip 全路径结构对照

no-skip U-Net 使用与 baseline U-Net 相同的患者、种子、八节点状态定义、干预算子和统计方法。其作用不是证明某条跳接为唯一原因，而是检验 PPTT 对已知结构改变是否具有过程诊断敏感性。

对模型 \(a,b\) 定义患者等权的全路径过程距离：

\[
D_{\mathrm{proc}}(a,b)
=\frac{1}{8}
\sum_{r=1}^{8}
\sum_{q\in\mathcal S_r^{\mathrm{eval}}}
\pi_{r,q}
\operatorname{TV}\!\left(
K_{a,r}(\cdot\mid q),K_{b,r}(\cdot\mid q)
\right),
\]

其中 \(\pi_{r,q}\) 为预先锁定的状态均衡权重。结构敏感性比较：

\[
\Delta D_{\mathrm{struct}}
=D_{\mathrm{proc}}(\text{U-Net},\text{no-skip})
-D_{\mathrm{within}}(\text{U-Net seeds}).
\]

若 \(\Delta D_{\mathrm{struct}}\) 的患者级置信区间下界大于零，说明方法识别出的结构间过程差异超过同架构随机种子波动。节点贡献必须完整报告，用于定位差异沿全网络如何分布；不能只展示最有利的 decoder 节点。

已有的早期差距、中部低谷、后期恢复与饱和现象作为结构对照的预声明解释目标，但不作为跨架构共同机制的定义，也不把 no-skip 写成独立架构族。

## 10. 可证明性质

### 10.1 最小范数唯一性

将线性约束写为 \(A_{\Omega,r}\delta h=\Delta l_\Omega\)。若 \(\Delta l_\Omega\) 位于 \(A_{\Omega,r}\) 的值域，则：

\[
\delta h^*=A_{\Omega,r}^{+}\Delta l_\Omega
\]

是所有可行解中唯一的最小欧氏范数解。任一其他可行解均可写为 \(\delta h^*+v\)，其中 \(v\in\operatorname{Null}(A_{\Omega,r})\)，且：

\[
\|\delta h^*+v\|_2^2
=\|\delta h^*\|_2^2+\|v\|_2^2.
\]

### 10.2 零空间读出不变性

对 \(v\in\operatorname{Null}(A_{\Omega,r})\)：

\[
A_{\Omega,r}(h+v)=A_{\Omega,r}h.
\]

因此，等范数零空间控制在观察器定义的目标状态上保持不变；若它仍产生与任务编辑相同的下游变化，则当前高层状态不具有特异解释力。

### 10.3 全路径误差上界

若每一步网络反事实核与高层核满足：

\[
\sup_{s\in\mathcal S}
\operatorname{TV}\!\left(K_t^N(\cdot\mid s),K_t^H(\cdot\mid s)\right)
\le\varepsilon_t,
\]

则由随机核的总变差压缩性和逐项替换，有：

\[
\operatorname{TV}\!\left(
\mu K_r^N\cdots K_8^N,
\mu K_r^H\cdots K_8^H
\right)
\le\sum_{t=r}^{8}\varepsilon_t.
\]

该定理说明局部误差如何累积到终点，但不替代各节点的实测门控。

### 10.4 跨网络反事实差异上界

若 U-Net 和 TransUNet 对同一高层干预分别在 \(\varepsilon_U\) 和 \(\varepsilon_T\) 内近似同一个 \(H_{\mathrm{shared}}\)，则：

\[
\operatorname{TV}\!\left(
P_U^{\operatorname{do}},P_T^{\operatorname{do}}
\right)
\le\varepsilon_U+\varepsilon_T.
\]

这一定理形式化了“共享高层机制”：两个网络的抽象反事实行为受同一模型约束，而不是它们具有相同低层结构。

### 10.5 证明边界

上述内容能够严格证明算子性质和条件误差界，不能在不加假设的情况下证明观察器恢复了网络唯一真实语义。共同机制是否成立仍由预声明架构、数据分布、节点和干预族上的经验门控决定。

## 11. 数据隔离与正式统计

### 11.1 单数据集隔离

本阶段只使用 BraTS2023：

- train：沿用冻结模型与观察器训练资产，不参与新结论拟合；
- validation：估计 \(H_U\)、\(H_T\)、\(H_{\mathrm{shared}}\)，校准自然编辑范数、泄漏和源—基础配对规则；
- test：执行锁定后的全节点反事实验证和患者级统计。

BraTS2023 test 已在此前 V3--V10 中使用，因此本阶段属于**锁定协议下的回顾性扩展验证**，不能描述为未接触的独立确认。新规格、代码哈希、阈值和患者清单必须在读取本阶段正式干预结果前冻结。

### 11.2 患者等权统计

所有像素先在患者内汇总，再在患者间等权。背景、水肿、坏死/非增强肿瘤核心和增强肿瘤分别报告，并以类别宏平均和最坏类别共同门控，背景不能凭借像素数量支配主要指标。像素的空间相关性不通过独立像素假设处理；置信区间采用患者级分层自助法 10,000 次，多节点假设检验采用 Holm 校正。

### 11.3 主要误差

对模型 \(m\)、种子 \(s\)、干预节点 \(r\)、源状态 \(q\) 和下游深度 \(t\)：

\[
\epsilon_{m,s,r,q,t,c}
=\frac12\sum_{a\in\mathcal S}
\left|P_N(a\mid y=c)-P_H(a)\right|.
\]

同时报告：

\[
\operatorname{IA}^{\mathrm{dist}}_{m,s,r,q,t,c}
=1-\epsilon_{m,s,r,q,t,c}.
\]

该量是随机高层模型的分布一致率，不等同于经典确定性交换干预一致率。主要结论以总变差误差和置信区间为准。

## 12. 正式运行前锁定的成功门槛

### 12.1 资产与覆盖门槛

每个模型—种子—节点必须满足：

1. 模型、观察器、患者清单和节点适配器哈希一致；
2. 使用锁定 test 清单中的全部合格患者，不以结果筛选病例；
3. 至少 100 名患者存在可评估干预；
4. 至少两个非平凡源状态可评估；
5. 每个纳入主门控的源状态覆盖至少 50 名患者和 128 个患者内限额采样像素；
6. 目标对数几率重构最大绝对误差不超过 \(10^{-5}\)；
7. 目标状态实现率不低于 0.95；
8. 完整恢复输出最大绝对误差不超过 \(10^{-6}\)；
9. 编辑范数和非目标泄漏通过 validation 锁定门槛。

任一节点不满足时记为 `INSUFFICIENT_INTERVENTION_SUPPORT` 或对应失败状态，并使全网络门控失败。

### 12.2 主机制门槛

U-Net 与 TransUNet 的三个种子和八个节点均须满足：

1. **绝对忠实度**：每节点状态—类别宏平均 TV 误差不超过 0.15；全网络最坏节点—状态—类别—深度误差不超过 0.20，95% 置信区间上界不超过 0.25；
2. **双向迁移**：\(H_U\rightarrow\)TransUNet 与 \(H_T\rightarrow\)U-Net 均通过绝对忠实度门槛；
3. **共享非劣性**：\(H_{\mathrm{shared}}\) 相对对应架构特异模型的 TV 增量不超过 0.03，95% 置信区间上界不超过 0.05；
4. **任务特异性**：\(\Delta G\ge0.10\)，且 95% 置信区间下界大于 0.05；同时 \(\operatorname{TV}(P_{\mathrm{null}},P_{\mathrm{clean}})\le0.05\)；
5. **顺序特异性**：正确节点顺序相对深度置乱模型的一致率优势至少 0.10，Holm 校正后 \(p<0.05\)；
6. **剂量一致性**：至少 90% 的节点—状态条件随 \(\lambda\) 增大沿高层预测方向变化，且任一节点不存在显著反向剂量关系。

所有阈值在正式 test 干预前写入协议锁。总体平均通过不能替代任一最坏节点失败。

### 12.3 结构对照门槛

no-skip 对照不参与跨架构主机制的通过判定，但必须完整执行八节点协议，并检验：

1. \(\Delta D_{\mathrm{struct}}>0\) 且患者级 95% 置信区间下界大于零；
2. 结构间全路径差异超过 baseline U-Net 三种子内部波动；
3. 所有节点贡献均报告，已知 decoder 后期恢复/饱和差异只作为完整过程剖面的组成部分；
4. 终点 Dice 差异与过程距离并列报告，用于检验相近终点是否可能掩盖更大的形成路径差异。

## 13. 结论决策表

| 正式结果 | 允许结论 | 禁止结论 |
|---|---|---|
| 两个主架构、三种子、八节点全部通过 | 在 BraTS2023 和预声明模型内，共享像素决策过程构成全网络近似高层因果抽象 | 所有分割网络共享普适真实机制 |
| 双向迁移通过，但共享模型非劣性失败 | 两个架构的高层过程可相互迁移，但单一共享参数模型证据不足 | 同一个高层转移模型已成立 |
| 仅一个架构通过 | 该架构内存在有界过程抽象 | 跨架构共同机制 |
| 多数节点通过但任一节点失败 | 仅支持明确列出的节点区间 | 全网络机制 |
| 观察轨迹稳定但干预或控制失败 | PPTT 支持过程诊断 | 因果抽象或强机制 |
| 零空间、随机化或置乱控制同样通过 | 当前抽象可能由粗粒度或映射自由度造成 | 任何因果机制主张 |
| 主机制通过且 no-skip 结构对照分离 | 该方法既具有跨架构高层一致性，也能识别结构改变造成的过程差异 | no-skip 证明某条跳接是唯一原因 |
| no-skip 未与同架构种子波动分离 | 结构敏感性证据不足 | 方法能可靠诊断结构改变 |

## 14. 第一性原理与对抗式审查

| 审稿质疑 | 当前设计的直接回答 | 失败时的处理 |
|---|---|---|
| 只是线性探针换名 | 探针只定义受限状态读取；核心检验是低层状态交换后整条下游轨迹是否符合共享高层模型 | 可读但干预不一致时只保留观察性过程诊断 |
| 高层模型过于灵活 | 只使用五状态、八个固定转移核和线性映射，不输入架构标签，不学习非线性对齐 | 随机或置乱控制通过即否定机制主张 |
| pooled 模型只是平均折中 | 同时要求双向跨架构迁移和相对架构特异模型非劣 | 任一失败均不得称同一模型 |
| 只挑选有利节点 | 八节点预声明，干预后记录全部下游深度，结论由最坏条件决定 | 任一节点失败即降级为局部范围 |
| 干预离开自然表示分布 | 自然源状态、最小范数闭式编辑、剂量曲线、范数和泄漏门控 | 超限条件记为 OOD，不当作零效应 |
| 同一状态模型不等于同一物理机制 | 只主张高层近似因果抽象，明确允许不同低层实现 | 不使用相同物理路径或唯一真实机制表述 |
| 单数据集不足以支持普适性 | 结论严格限于 BraTS2023 与两种预声明主架构 | 不写其他数据分布或所有网络规律 |
| test 已被此前实验使用 | 本阶段明确标记为锁定协议下的回顾性扩展验证 | 不称未接触独立确认 |
| 五状态的一阶假设可能过粗 | validation 上先做历史依赖准入，并在 test 中按肿瘤类别报告最坏误差 | 一阶准入失败时停止，不临时换高容量模型 |
| 像素存在强空间相关 | 以患者为统计单位，像素只在患者内形成条件分布 | 不把像素数量当作独立样本量 |
| 方法依赖真实标签定义状态 | 当前定位为有标注数据上的训练后机制审计工具 | 不称为无标注临床在线解释方法 |
| no-skip 又把研究拉回跳接 | no-skip 只作为已知结构改变的全路径敏感性对照，主门控仍是 U-Net 与 TransUNet | 不把局部跳接重要性写成主方法 |
| 终点差异不大，研究价值有限 | 方法检验相近终点下是否存在显著且可干预复现的过程差异 | 若过程效应也小或不稳定，则承认实用价值有限 |

## 15. 创新与价值边界

### 15.1 可主张的方法创新

1. 把医学分割网络内部推理表示为保留像素身份的决策关系状态过程，使不同低层架构能够在同一高层空间比较；
2. 提出输出约束的最小范数状态交换，把高层像素决策干预闭式翻译到异构节点特征空间；
3. 通过双向跨架构迁移、共享模型非劣性和全节点反事实轨迹检验，将观察性状态转移提升为有条件的高层因果抽象；
4. 用最坏节点门控、全路径误差上界和零空间/置乱/随机化控制限制空洞解释；
5. 用 no-skip 全路径对照验证方法能够识别结构改变引起的过程差异，而不依赖某条架构特异路径作为方法定义。

### 15.2 对其他研究者的直接价值

该方法提供三类可复用诊断能力：

- 判断两个终点性能相近的分割网络是否通过不同的像素修正、破坏和错误重编码过程形成结果；
- 定位过程差异发生在哪些宏观阶段，并用干预检验这些状态是否参与后续输出形成；
- 在不同架构之间使用同一高层语言比较推理过程，为结构选择、模块诊断和后续机制研究提供可检验假设。

### 15.3 不主张原创的部件

线性观察器、Moore--Penrose 逆、有限状态过程、激活编辑、患者级自助法、U-Net 与 TransUNet 均有既有基础。创新性不能落在这些工具单独使用上，而应落在**像素决策过程对象、闭式同义干预、跨架构共享高层模型和全路径反事实验证**构成的整体方法上。

正式论文写作前仍需执行独立新颖性检索；若发现同构方法，贡献表述必须下调，不能使用绝对首次。

## 16. 实现阶段与非发散执行顺序

### V11-A：数学与受控测试

1. 验证最小范数解、目标重构、零空间不变性和剂量线性；
2. 用已知五状态过程验证高层核恢复和全路径误差上界；
3. 构造终点相同但过程不同的受控网络，确认终点指标无法区分而 PPTT 能区分；
4. 确认随机观察器、深度置乱和状态置换不能通过门控。

该阶段只验证实现和理论，不形成真实医学结论。

### V11-B：既有资产与节点审计

1. 核验 U-Net、no-skip U-Net、TransUNet 三种子权重；
2. 核验八节点适配器、观察器、数据清单和现有轨迹哈希；
3. 确认所有模型能完成节点读取、激活回写和完整恢复；
4. 不训练新的分割模型。只有观察器资产缺失或与模型哈希不匹配时，才按冻结协议重新计算对应观察器，并明确记录原因。

### V11-C：验证集建模与协议锁

1. 估计 \(H_U\)、\(H_T\) 与 \(H_{\mathrm{shared}}\)；
2. 完成一阶过程假设的五折历史依赖准入；
3. 校准自然配对、编辑范数、非目标泄漏和状态覆盖；
4. 冻结节点、状态、剂量、阈值、患者、统计假设和代码哈希；
5. 完成协议锁后才运行本阶段正式 test 干预。

### V11-D：两个主架构的全节点反事实验证

1. 对 U-Net 与 TransUNet 的三种子、八节点执行状态交换；
2. 每次编辑捕获全部后续节点和终点；
3. 同步执行等范数零空间、深度置乱、状态置换和随机观察器控制；
4. 计算双向迁移、共享非劣性、剂量一致性和最坏节点门控。

### V11-E：no-skip 全路径结构对照

1. 使用同一协议处理 no-skip U-Net；
2. 比较 baseline/no-skip 的全路径过程距离与 baseline 种子内波动；
3. 将已知早期差距、中部低谷和后期恢复/饱和放回完整节点序列解释；
4. 不追加局部跳接、频率、区域或注意力实验。

### V11-F：统计汇总与结论审计

1. 生成患者级正式表、95% 置信区间和 Holm 校正结果；
2. 按资产、覆盖、算子、忠实度、特异性和最坏节点顺序执行门控；
3. 输出通过、失败或覆盖不足，不允许结果导向补实验；
4. 对照第 13 节生成唯一结论级别和禁止表述清单。

- [Boundless Distributed Alignment Search, NeurIPS 2023](https://proceedings.neurips.cc/paper_files/paper/2023/hash/f6a8b109d4d4fd64c75e94aaf85d9697-Abstract-Conference.html)：高容量分布式对齐的能力与空洞化风险参照。
- [Neural Causal Abstractions, AAAI 2024](https://ojs.aaai.org/index.php/AAAI/article/view/30044)：神经网络高层因果抽象的学习视角。
- [Causal Abstraction Inference under Lossy Representations, ICML 2025](https://openreview.net/forum?id=WDybFnCPaB)：有损表示下近似因果抽象的理论边界。
- [MIB: A Mechanistic Interpretability Benchmark, ICML 2025](https://openreview.net/forum?id=sSrOwve6vb)：机制解释的忠实度、精确性与控制要求。
- [TransUNet](https://arxiv.org/abs/2102.04306)：混合 CNN--Transformer U 形分割架构依据。

## 21. 冻结项与非目标

- 不修改 V0--V10 的正式患者、阈值、候选、结果或结论；
- 不把 CAM、LayerCAM、SHAP、响应熵或特征范数纳入 PPTT 方法；
- 不新增数据集或额外主架构；
- 不训练新的分割模型；
- 不通过挑选终点 Dice 差异更大的种子体现价值；
- 不增加与共享高层状态转移机制无关的局部边、区域、频率或注意力实验；
- 不把 no-skip 对照写成第三个独立架构族；
- 不把通过部分节点写成全网络通过；
- 不把 BraTS2023 上两个架构的结果写成所有网络的普适规律；
- 不在正式实验与审计完成前制作结果导向的论文主图或修改结论。
