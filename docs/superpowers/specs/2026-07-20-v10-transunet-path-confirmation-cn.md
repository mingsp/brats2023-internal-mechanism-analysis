# V10 TransUNet 路径特异顺序确认规格

## 1. 目的

V9 严格限定为 V8 三个种子均未执行任何干预的 26 名共同患者。该队列在 `skip_down3_to_up1` 上仅产生 `6/7/6` 个过程端点可评估组合和 1 个区域特异性可评估组合，未达到每种子 20 名的预注册门槛。V10 不修改 V9，而是在同一候选、同一算子和同一匹配门槛下，对尚未接受过该候选路径干预的其余测试患者执行一次顺序确认。

## 2. 固定要素

- 候选固定为 V9 在验证集联合过程效应与匹配可行性准入后登记的 `skip_down3_to_up1`，不重新排序候选。
- 干预仍为逐通道保持值多重集合的空间循环平移，以及目标区域或等量匹配对照区域的干净激活恢复。
- 目标像素、目标特征位置和匹配位置门槛仍为 `32/8/8`。
- 恢复剂量仍为 `0.25/0.50/0.75/1.00`。
- 正式队列为 250 名测试患者中排除 V9 的 26 名患者后剩余的 224 名患者。V10 锁定前不得存在这些患者在 `skip_down3_to_up1` 上的干预输出。

V8 对同一数据集执行的是 `bottleneck_to_up1`，不改变模型参数，也不提供 V10 路径的反事实结局。V10 不具有新数据集独立性，因此只能作为同一测试集内经过多轮校正的路径特异顺序确认。

## 3. 多重检验

V8、V9 和 V10 三轮确认统一按 `alpha = 0.05/3` 解释；每轮端点与种子内部继续使用全局 Holm 校正。最低标准化效应保持 `0.8`，每个端点每种子至少 20 名患者，患者级剂量单调比例至少 `0.8`。

## 4. 成功条件

至少两个模型种子同时通过必要性、恢复性和区域特异性；至少两个种子通过总体及患者级剂量关系；全部路径身份、恢复误差、循环平移多重集合和钩子清理审计通过。

## 5. 停止规则

首次正式运行前锁定候选、224 人有序清单、代码、数据、模型、观察器、V8/V9 状态与统计规则。正式运行后无论通过、覆盖不足或效应失败，均停止 TransUNet 路径确认，不更换候选、不改变队列、不放宽门槛。
