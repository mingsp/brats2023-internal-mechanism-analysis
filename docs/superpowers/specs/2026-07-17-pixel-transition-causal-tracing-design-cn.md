# 像素转移因果追踪设计规格

## 1. 目标

本实验检验一个限定性因果问题：验证集选出的 `up1→up2` 持续净恢复差异，是否依赖有跳接 U-Net 在 `up2` 接收的 `down2` 空间对齐特征。实验不证明网络存在唯一真实机制，只检验预定义高层像素状态、低层跳接变量和干预算子之间的反事实一致性。

## 2. 进入依据与边界

原双指标门控要求中部破坏和后期持续恢复同时在至少两个种子达到大效应。该门控未通过：中部破坏在三个种子方向一致且显著，但仅一个种子的配对效应量不低于 0.8。后期持续恢复在三个种子均达到大效应。验证集上的候选选择完全独立于干预结果，`up1→up2` 在种子 42、123、3407 上的差异分别为 0.1120、0.1007 和 0.0781，配对效应量分别为 2.24、2.02 和 2.11。

因此，因果实验仅检验 `up1→up2` 后期持续恢复，不把中部破坏纳入因果结论。阈值、候选路径、种子、病例集合、干预剂量和统计规则在首次干预前固定，干预结果不得用于改动这些设置。

## 3. 高层因果变量

对真值为肿瘤类别的像素，设有跳接模型的干净节点状态为 `s_1,…,s_8`，候选转移索引为 `t=4`，即 `up1→up2`。干净持续纠正集合定义为：

```text
P_t = {p | s_t(p) != y(p), s_{t+1}(p) = y(p),
           s_k(p) = y(p) for every k >= t+1,
           transition t is reliable at p}.
```

干预条件 `c` 下的持续纠正保留率定义为：

```text
Q(c) = mean_{p in P_t} 1[s_k^c(p) = y(p) for every k >= t+1].
```

主要反事实量为：

```text
TE = Q(clean) - Q(corrupt)
IE(alpha) = Q(restore_target, alpha) - Q(corrupt)
PM(alpha) = IE(alpha) / TE
```

当 `TE<=0` 时，病例不提供可解释的恢复比例，但仍保留在必要性统计和失败审计中。

## 4. 低层变量与干预

低层变量固定为有跳接 U-Net 的 `up2` 模块第二个输入，即 `down2` 跳接特征。该特征空间大小为 `C×H×W`，候选像素集合通过自适应最大池化映射到 `H×W`，避免使用插值产生不存在的目标位置。

干预条件如下：

- `clean`：不改变跳接特征。
- `corrupt`：将完整跳接特征在空间上循环平移 2 个特征单元，对应输入图像约 8 个像素，破坏空间对齐但保持特征向量多重集合不变。
- `restore_target(alpha)`：以 `alpha∈{0.25,0.50,0.75,1.00}` 将候选区域从平移特征插值恢复到干净特征。
- `restore_control(1.00)`：在相同破坏条件下，只恢复与候选区域数量相同、类别和位置条件匹配的稳定正确区域。
- `no_skip_negative_control`：对无跳接 U-Net 的同名 `up2` 第二输入执行相同变换。该输入只提供尺寸信息，特征值不参与卷积计算，输出应保持逐像素一致。

候选区域恢复检验空间局部充分性；匹配区域恢复检验区域特异性；无跳接负控制检验实现和路径特异性。

## 5. 病例和切片规则

模型种子固定为 42、123 和 3407。干预使用测试集全部 250 名患者，不按结果挑选病例。每个模型-种子-患者组合先由干净轨迹确定持续纠正像素最多的切片，平局时选切片编号最小者。切片至少包含 32 个持续纠正像素，映射后至少包含 8 个候选特征位置；不满足条件的病例记录为不可评估，不静默替换。

匹配对照来自同一切片的稳定正确肿瘤区域，并排除候选区域。特征位置按主导真值类别、肿瘤边界距离和干净激活范数匹配，不放回抽样。匹配不足时该病例的区域特异性端点记为不可评估，必要性端点仍保留。

## 6. 统计与成功标准

主要端点按患者配对统计，并对三个种子分别报告均值差、95% 自助法置信区间、Wilcoxon 检验、配对 Cohen's d 和秩二列相关。主要检验族采用 Holm 校正。

因果忠实性成立需要同时满足：

1. 必要性：至少两个种子的 `TE` 置信区间下界大于 0，Holm 校正后 `p<0.05`。
2. 恢复性：至少两个种子的 `IE(1.00)` 置信区间下界大于 0。
3. 区域特异性：至少两个种子的 `IE_target(1.00)-IE_control(1.00)` 置信区间下界大于 0。
4. 剂量关系：至少两个种子的群体均值 `Q` 随恢复剂量单调不减。
5. 负控制：无跳接模型在相同输入钩子变换下的最大 logit 误差不超过 `1e-6`，状态不一致数为 0。
6. 恢复审计：`alpha=1` 的目标区域确实恢复为干净激活，钩子在每次前向后清除。

若任一必要条件失败，结果只能表述为路径敏感性或过程诊断，不得表述为结构因果机制得到证明。

## 7. 输出

正式输出包括患者级干预表、种子级统计表、剂量审计、匹配审计、负控制审计、协议状态和一张因果结果图。因果图只展示干净、破坏、候选恢复和匹配对照的同一病例同一切片，以及群体剂量和效应量，不增加无关实验面板。
